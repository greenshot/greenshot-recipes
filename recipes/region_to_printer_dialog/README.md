# Region to Printer (with dialog)

Captures a region you select and opens the system printer dialog. Greenshot's destinations picker is skipped.

## Use it

- Tray menu: **Region to Printer (with dialog)**
- Hotkey: Ctrl + Alt + Shift + D, change it in Settings > General or in the recipe editor

## Options

| Option | Default |
|---|---|
| Hotkey | Ctrl + Alt + Shift + D |

## Allows

Opens the system printer dialog so you can choose a printer and print settings.
